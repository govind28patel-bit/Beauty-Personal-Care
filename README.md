# DermaSafe — Beauty & Personal Care UX Case Study

An allergy-aware skincare ingredient checker built for Indian skin. DermaSafe checks a mixed shelf (prescribed, Ayurvedic and unbranded products) against a person’s own allergy profile and shows the source behind every warning.

## What’s inside the case study

1. Problem and problem statement
2. Process (double diamond)
3. Secondary research, with sources
4. Business opportunity: market size, revenue model, go-to-market, risks
5. Value proposition canvas and fit check
6. MoSCoW scope
7. Seven-stage flow with a job to be done and a KPI per stage
8. Key screens and states (live prototype screens)
9. Design system and component library
10. Trust by design, success metrics, decisions from critique
11. Review checklist
